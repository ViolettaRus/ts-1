## Цель репозитория
Небольшой учебный проект для демонстрации типизированной функции расчёта стоимости товара с учётом скидки и, при необходимости, рассрочки на заданное количество месяцев.

## Задача и функциональные требования
- **Что решаем**: корректно считать итоговую стоимость с учётом скидки в процентах. Если включена рассрочка, вычислять ежемесячный платёж.
- **Функциональные требования**:
  - Валидация входных данных: цена ≥ 0, скидка в диапазоне 0..100, количество месяцев — целое положительное.
  - Поддержка двух режимов:
    - Без рассрочки: вернуть общую стоимость со скидкой.
    - С рассрочкой: вернуть ежемесячный платёж.
  - Округление результата до копеек (2 знака).

## Структура репозитория
- `totalPrice.ts` — публичная функция `totalPrice`, использующая утилиты и константы.
- `totalPrice.types.ts` — тип `TotalPriceParams` с union-типизацией параметров для режимов с/без рассрочки.
- `pricing.constants.ts` — общие константы: границы скидки и точность округления.
- `pricing.utils.ts` — утилиты: проверки входных параметров, применение скидки, округление до копеек.

Взаимодействие модулей:
- `totalPrice.ts` импортирует вспомогательные функции из `pricing.utils.ts`, которые опираются на значения из `pricing.constants.ts`. Типы параметров импортируются из `totalPrice.types.ts`.

## Как запускать и использовать
Ниже — несколько вариантов. Выберите удобный.

### Вариант A: Быстрый запуск через ts-node
Требуется Node.js и `ts-node`.

```
# однократно установить ts-node (или используйте npx)
npm i -g ts-node typescript

# запуск примера (предполагается, что внутри totalPrice.ts есть пример вызова)
ts-node totalPrice.ts

# либо через npx без глобальной установки
npx ts-node totalPrice.ts
```

### Вариант B: Компиляция в JS через tsc и запуск node
```
# установить TypeScript, если не установлен
npm i -g typescript

# скомпилировать одиночный файл (создаст totalPrice.js рядом)
tsc totalPrice.ts

# запустить Node.js
node totalPrice.js
```

### Пример кода использования
```
import { totalPrice } from "./totalPrice";

const price = totalPrice({ price: 100000, discount: 25, isInstallment: true, months: 12 });
console.log(price); // 6250
```

## Тестирование
Пока проект без фреймворка тестов. Проверка вручную:
- запустить пример из `totalPrice.ts` (см. раздел «Как запускать»);
- изменить входные данные и убедиться в корректной обработке валидных/невалидных случаев.

При желании можно быстро подключить Jest или Vitest:
- инициализировать npm-проект (`npm init -y`),
- установить `vitest` или `jest` и `ts-node`,
- добавить тесты на позитивные и негативные сценарии: скидка 0/100, цена 0, невалидные `months`, и т.д.

## Важные детали
- Все числовые входы валидируются, при некорректных данных выбрасываются ошибки с понятными сообщениями.
- Округление до 2 знаков контролируется константой `ROUND_PRECISION_CENTS` в `pricing.constants.ts`.
- Границы скидки сконцентрированы в `pricing.constants.ts` (`DISCOUNT_MIN`, `DISCOUNT_MAX`).
- Типы параметров разделены на режимы с/без рассрочки, что предотвращает некорректные комбинации аргументов на этапе компиляции TypeScript.
